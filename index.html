Where the data come from and how the numbers are computed

Source
The game log is the Memphis Grizzlies 2012–13 regular-season schedule and results, as published by Basketball-Reference.com, saved as games.csv in this site’s repository. The trade date, January 30, 2013, comes from news reports of the three-team deal with Toronto and Detroit, such as Sports Illustrated’s report.
What one row is
One regular-season game played by the Grizzlies, with its date, venue (home or away), opponent, result, and both teams’ points. A game is Before if it was played before January 30, 2013 (games 1–44, through January 28) and After if it was played on or after that date (games 45–82, from January 31). No game was played on January 29 or 30.
Rows dropped
None. The file has … rows and … are used, so … were dropped. A row would be dropped only if it lacked a valid date, a win or loss result, a home or away label, an opponent, or either team’s points. Playoff games are not in the file. The one October game (October 31, a loss) is counted in the Before period.
How each summary number is computed
  • Win % before the trade = wins ÷ games, for Before games.
  • Win % after the trade = wins ÷ games, for After games.
  • Change in win % = (win % after − win % before) × 100, in percentage points.
  • Change in average point margin = average of (Grizzlies points − opponent points) over After games, minus the same average over Before games.
What this data cannot tell you
The file has no player information, so it cannot separate Rudy Gay’s departure from the other changes that came with the trade, or from injuries, rest, and the strength of the opponents faced. Each period is a different length (… and … games), so the report compares rates, not totals. Read it as “the team did better after the trade,” not “the trade caused it.”
